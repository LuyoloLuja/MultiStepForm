# Multi Step Form - [Frontend Mentor Challenge](https://www.frontendmentor.io) 

This multi step form helps gamers choose different types of plans depending on the selected game type

## Table of Contents
- [Installation](#installation)
- [Technologies Used](#technologies-used)

## Installation

1. Clone the repository:
   ```code
   git clone https://github.com/LuyoloLuja/MultiStepForm.git
   ```
2. Navigate into the project folder:
    ```code
    cd MultiStepForm
    ```
3. Install dependencies:
    ```code
    dotnet restore
    ```
4. Run application
    ```code
    dotnet run
    ```
## Technologies used
